# Trek photos

the site automatically. Until a photo exists, a drawn mountain scene is shown
instead, so nothing ever looks broken.

## Tips

- Use **landscape** photos, at least 1600 px wide. Keep each file under ~400 KB
  (compress at squoosh.app) so pages load fast.
- The file name must match exactly, all lower case, ending in `.jpg`.
- If you add a new trek in the office screens, its file name is the trek name in
  lower case, with `&` written as `and` and spaces/other symbols as `-`.

## Where to get free photos

- Unsplash: search "K2", "Hunza", "Fairy Meadows", "Deosai", "Rakaposhi"
- Wikimedia Commons: commons.wikimedia.org (check the licence; most need you to
  credit the photographer, e.g. in the footer or your report)
- Pexels: pexels.com

Do not use random Google Images results: most are copyrighted.
